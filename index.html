Guías para Administradores

Tutoriales de Configuración y Permisos

Aprende a configurar el bot correctamente en menos de 2 minutos para evitar errores de comandos.

1. Otorgar Permisos de Administrador

Para que comandos como /ban, /setup-support o /serverstats setup funcionen, el rol de Bloblox Support debe tener permisos de Administrador.

2. Activar el Sistema de Tickets

Dirígete al canal de ayuda y escribe /setup-support. El bot desplegará automáticamente el panel interactivo permanente para atender consultas.

3. Configurar Estadísticas de Voz

Utiliza el comando /serverstats setup. El bot creará canales de voz estáticos arriba del todo mostrando el total de miembros en tiempo real.
